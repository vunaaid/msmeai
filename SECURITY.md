# Security Policy

## Báo cáo lỗ hổng / Reporting a Vulnerability

**🇻🇳** Vui lòng **KHÔNG** mở issue công khai cho lỗ hổng bảo mật. Gửi báo cáo riêng
qua email: **vuna.aid@gmail.com**.

**🇬🇧** Please do **NOT** open a public issue for security vulnerabilities. Report
them privately by email: **vuna.aid@gmail.com**.

Trong báo cáo, vui lòng kèm / Please include:

- Mô tả lỗ hổng và ảnh hưởng / Description of the vulnerability and its impact.
- Các bước tái hiện / Steps to reproduce (proof of concept if possible).
- Phiên bản / commit bị ảnh hưởng / Affected version or commit.

## Quy trình xử lý / Process

- Chúng tôi sẽ phản hồi trong vòng **7 ngày** / We aim to acknowledge within **7 days**.
- Sau khi xác nhận, chúng tôi sẽ phối hợp khắc phục và thống nhất thời điểm công bố.
  After confirmation, we coordinate a fix and an agreed disclosure date.
- Người báo cáo có thiện chí sẽ được ghi nhận (nếu đồng ý) / Good-faith reporters
  will be credited if they wish.

## Phạm vi / Scope

Chính sách này áp dụng cho mã nguồn trong repository này. / This policy covers the
source code in this repository.
